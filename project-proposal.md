name: Project Proposal
---

Write up a project proposal based on our conversation.

The title should be concise and to the point.

It should start with a TLDR, one paragraph that summarizes why we might want to tackle this project with one or two important cons if they are necessary or worth noting.

Let's not write a novel, but let's give stakeholders enough information to weigh the pros and cons. Remember that we are in the Laravel ecosystem.
